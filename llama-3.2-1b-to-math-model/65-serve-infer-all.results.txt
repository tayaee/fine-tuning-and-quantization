    어디까지 가능한가
        순수 SFT(지도 학습)만으로는 1B 모델에 데이터를 아무리 쏟아부어도 GSM8K 해결에 명확한 한계가 오지만
        RL(강화학습)과 장문 CoT(Test-Time Compute)를 결합하면 1B 모델로도 80~85% 이상의 높은 정답률을 달성할 수 있습니다

    1B급 모델 중 GSM8K 최강자
        Qwen2.5-Math-1.5B
            수식, 코드, 논문텍스트 수조 개의 토큰으로 학습한 모델
            CoT 기준 84~85%
            코드 실행 결합 시 88%
        DeepSeek-R1-Distill-Qwen-1.5B
            수만개의 단계별 검증 데이터 사용하여 학습한 모델
            88 ~ 89%

    어느 수학 베이스 모델에서 시작하면 좋을까
        Qwen2.5-Math-1.5B
        DeepSeek-R1-Distill-Qwen-1.5B

    최상 품질 1B 수학 모델 만들려면 데이터 얼마나 준비해야 할까
        SFT용
            고품질 다단계 CoT 증류 데이터 50k ~ 100k 필요
            답만 포함시키면 100% 오답만 낸다. CoT 필요함.
        Verifiable RL용
            문제 + 정답 규칙 (rule-based verifier) 20k ~ 50k 필요
        TIR (Tool-integrated) 병행 시
            Python 코드 포함 데이터 30k ~ 50k 필요
            코드 실행하여 값을 가져오게 튜닝하면 20~30%p 정답률 상승 가능하다.
